# Road Runner Game - Roblox

A Road Runner–style chase game built on Roblox.

## Project structure

```
docs/     Design notes and documentation
src/
  server/ Server scripts (ServerScriptService)
  client/ Client scripts (StarterPlayerScripts)
  shared/ Modules shared by server and client (ReplicatedStorage)
images/   Screenshots, thumbnails and concept art
```

## Getting started

1. Install [Roblox Studio](https://create.roblox.com/).
2. Clone this repository:
   ```
   git clone https://github.com/TheAwesomeSage/road-runner-game-roblox.git
   ```
3. Optionally, use [Rojo](https://rojo.space/) to sync the `src` folder into Studio.
